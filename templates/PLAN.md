# 전체 계획

**한 줄 목표**　사용자 행동 → 보이는 결과

**시험 시계**　남은 HH:MM:SS(실제/추정) · 기준 측정 시각 미확인 · 작업 가능 시간 미산정

## 구현 뼈대

입력 → 처리 → 저장 → 출력

| 주요 파일·함수(예정/실제) | 비유 · 하는 일 | 앞뒤로 받거나 넘기는 것 |
|---|---|---|

**상태 저장 위치**　실제 파일·테이블 또는 메모리, 재시작하면 어떻게 되는지

| 큰 기술 선택 | 쓰는 이유 | 대안이 유리해지는 조건 |
|---|---|---|

## 더 나은 결과를 고르는 기준

필수 제약 / 가능한 결과 A·B의 차이 / 내가 궁금해한 지표 / 잠정 기준과 실제 결과 후 변경 (선택 근거는 해당 WORK ②)

## 전체 진행표

| 라운드 | 끝나면 내가 보게 될 것 | 연결된 원문 요구 | 담당·순서/병렬 | 목표 잔여 HH:MM:SS | 진행·검증 |
|---|---|---|---|---|---|

**시간 이력**　라운드 · 기존 목표 · 실제/추정 잔여 · 차이 · 다음 목표 변경과 이유

**마무리**　최종 독립 검증 / 영향 재확인·제출 준비 / 복습 시간

**제외·미완료**　범위와 이유

**위험 상위 3**　발견한 것만
